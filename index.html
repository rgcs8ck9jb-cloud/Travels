How to add the next city

Two steps. The home page never changes.

  1. Upload the new guide to the repo root, named after the city — khiva.html, samarkand.html. Lower case, no spaces.
  2. Open trips.json → pencil icon → add one block to the trips list → Commit.

The block to copy

{
  "city": "Khiva",
  "country": "Uzbekistan",
  "dates": "August 2026",
  "start": "2026-08-20",
  "file": "khiva.html",
  "tag": "14 stops · 3 km · walking",
  "blurb": "One sentence about the guide.",
  "accent": "#b4552d"
}

Watch out for

  1. Put a comma after the previous block's closing } — a missing comma is the only thing that breaks this page.
  2. start is YYYY-MM-DD. It sorts the list and decides Upcoming vs Past. Nothing else uses it.
  3. accent is any hex colour — it tints the card stripe.
  4. GitHub Pages takes about a minute to rebuild. Pull down to refresh if you don't see it.

Add this page to your Home Screen

  1. Safari → Share → Add to Home Screen. The icon always opens this list, and every new city appears in it automatically.
