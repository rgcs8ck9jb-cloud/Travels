How to add the next city▾
Three files per city
  1. khiva.html — plan, map and stops
  2. khiva-food.html — what to order, where to eat
  3. khiva-info.html — heat, tickets, transport, kids
Two steps
  1. Upload all three to the repo root in one commit (Add file → Upload files).
  2. Open trips.json → pencil → add one block → Commit.
The block to copy
{
  "city": "Khiva",
  "country": "Uzbekistan",
  "dates": "21–22 August 2026",
  "start": "2026-08-21",
  "file": "khiva.html",
  "hotel": "Orient Star Khiva",
  "tag": "14 stops · 2 mornings",
  "blurb": "One sentence.",
  "accent": "#0F4C5C"
}
Watch out for
  1. Put a comma after the previous block's closing } — the only thing that breaks this page.
  2. start is YYYY-MM-DD. It sets the month heading and the sort order.
  3. The Food and Practical buttons are derived from file — name them <city>-food.html and <city>-info.html and they work automatically.
  4. Brand colours: teal #0F4C5C, coral #FF7A59.
