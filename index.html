How to add the next city
Two steps — the home page never changes
  1. Upload the guide to the repo root, named after the city: khiva.html. Lower case, no spaces.
  2. Open trips.json → pencil → add one block to the trips list → Commit.
The block to copy
{
  "city": "Khiva",
  "country": "Uzbekistan",
  "dates": "21–22 August 2026",
  "start": "2026-08-21",
  "file": "khiva.html",
  "hotel": "Orient Star Khiva",
  "tag": "14 stops · 2 mornings",
  "blurb": "One sentence.",
  "accent": "#0A5FE0"
}
Watch out for
  1. Put a comma after the previous block's closing } — a missing comma is the only thing that breaks this page.
  2. start is YYYY-MM-DD. It sets the month heading and the sort order.
  3. country drives the country sub-heading, even when there is only one city in it.
  4. GitHub Pages takes about a minute to rebuild.
Home Screen
  1. Safari → Share → Add to Home Screen. The icon always opens this list and picks up new cities automatically.
